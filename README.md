# Portfolio Website - Benedictus Abigail Triwiyatno

A modern, responsive portfolio website built with Next.js and TypeScript, showcasing my skills, projects, and experience as a Junior Web Developer.

## 🚀 Features

- **Responsive Design**: Optimized for all devices using Tailwind CSS
- **Dark/Light Mode**: Theme switching capability with next-themes
- **Smooth Animations**: Enhanced user experience with Tailwind animations
- **Modern UI Components**: Built with Radix UI primitives for accessibility
- **Fast Performance**: Powered by Next.js 16 with optimized builds
- **TypeScript**: Full type safety throughout the application

## 🛠️ Tech Stack

- **Framework**: Next.js 16
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **UI Components**: Radix UI
- **Icons**: Lucide React & React Icons
- **Forms**: React Hook Form with Zod validation
- **Charts**: Recharts
- **Analytics**: Vercel Analytics

## 📦 Installation

1. Clone the repository:
```bash
git clone https://github.com/your-username/portfolio.git
cd portfolio
```

2. Install dependencies:
```bash
npm install
# or
pnpm install
# or
yarn install
```

3. Run the development server:
```bash
npm run dev
# or
pnpm dev
# or
yarn dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🏗️ Build for Production

```bash
npm run build
npm start
```

## 🎨 Customization

### Personal Information
Update the following files to customize with your information:
- `components/hero.tsx` - Name, introduction, and profile image
- `components/about.tsx` - Personal background
- `components/skills.tsx` - Technical skills
- `components/projects.tsx` - Portfolio projects
- `components/contact.tsx` - Contact information

### Styling
- Colors and themes can be modified in `app/globals.css`
- Tailwind configuration in `tailwind.config.js`
- Component styles in respective component files

## 📱 Sections

1. **Header**: Navigation menu with smooth scrolling
2. **Hero**: Introduction with profile image and call-to-action buttons
3. **About**: Personal background and journey
4. **Skills**: Technical skills and competencies
5. **Projects**: Showcase of completed projects
